# Project | Capstone | Round 1 | Timeline Estimate
### John Adams

**Scope:** MVP covering all 3 proposed use cases

## Timeline

| Week | Work |
|---|---|
| Week 1 | Discovery and measurement setup, begin Use Case 1 build |
| Week 2 | Use Case 1 testing and training, begin Use Case 2 build |
| Week 3 | Use Case 2 testing, begin Use Case 3 build |
| Week 4 | Use Case 3 testing, full integration and owner training |

**Total: about 4 weeks** from kickoff to a working MVP covering all 3 use cases.

## Assumptions

| Assumption | Why |
|---|---|
| Salon owners are available for training and feedback within each week | Delays on the client side would extend the timeline beyond 4 weeks |
| Tool accounts (n8n, Twilio, LLM API, Airtable) are set up promptly at kickoff | The client owns and pays for these directly, so setup speed is outside consultant control |
| Consultant days (10.5 total, see `cost_analysis.md`) are spread across the 4 calendar weeks | Not worked back to back, this is a part-time engagement pace |
